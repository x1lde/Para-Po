# ParaPo! visual identity

This is the current visual specification and supersedes earlier lavender or Sakay blue designs.

| Role | Color |
| --- | --- |
| Warm yellow | #F9C846 |
| Deep teal | #117C83 |
| Orange | #FF6B35 |
| Charcoal | #24343B |
| Cream | #FFF9E9 |

Inter Regular, SemiBold, Bold and ExtraBold are bundled offline under the SIL Open Font License. Charcoal headings on a yellow gradient and cream surfaces keep the interface readable. Rounded cards, generous spacing, subtle shadows and brief press transitions support a focused commuting interface. Reduced-motion preferences are respected on web.

Phone layouts come first. Tablets gain two-column planning; desktops gain top navigation and content capped at 1200 px. See [mobile UI](mobile-ui.md) for behavior and validation. All active routes use this shared theme, including dark mode.
