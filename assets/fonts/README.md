# Bundled Inter fonts

Inter Regular, SemiBold, Bold and ExtraBold are bundled locally so typography works offline on Android, iOS and web. The files come from the Expo Google Fonts Inter package: https://github.com/expo/google-fonts/tree/master/font-packages/inter

Inter is designed by Rasmus Andersson and licensed under the SIL Open Font License 1.1. See OFL.txt. The license is mirrored from https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt.
